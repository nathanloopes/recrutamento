# recrutamento
Aplicação full-stack de recrutamento que automatiza o funil de contratação de ponta a ponta. O candidato se cadastra, descobre vagas e passa por uma entrevista conversacional por voz com avaliação automática das respostas; o RH acompanha tudo por um pipeline de vagas configurável, com agendamentos e notificações . empacotável para Android/iOS
